Ejercicio 1 de 15 Ecuación Logarítmica Básico ✨ Generado aleatoriamente

Resuelve la siguiente ecuación para x (descarta las soluciones que no pertenezcan al dominio):

log2(3x - 2) = 4

Formato admitido: enteros (4), fracciones (1/2, -5/2), decimales con punto o coma (2.26 o 2,26) y dos soluciones separadas por coma (2, -1).

⚠️ Regla de oro en ecuaciones logarítmicas (Comprobación obligatoria)

El logaritmo solo existe para argumentos estrictamente positivos y bases positivas distintas de 1: en loga(u) debe cumplirse siempre que u > 0, a > 0 y a ≠ 1. Al resolver la ecuación algebraica equivalente pueden aparecer soluciones extrañas que debes descartar tras comprobar en la ecuación original.

Definición de Logaritmo y Valores Notables

Relación fundamental entre potencias y logaritmos

Definición fundamental Esencial
loga(u) = y  ⇔  ay = u

El logaritmo en base a de u es el exponente y al que hay que elevar la base a para obtener u.

Ejemplo: log2(8) = 3 porque 23 = 8.
Notaciones habituales Bases
log(x) = log10(x)  |  ln(x) = loge(x)

Si no se escribe la base, se sobreentiende base 10 (logaritmo decimal). Si aparece ln, la base es el número e ≈ 2,718 (neperiano).

Ejemplo: log(100) = 2 ya que 102 = 100.
Identidades inmediatas Propiedades base
loga(1) = 0  |  loga(a) = 1  |  loga(ak) = k

Cualquier base elevada a 0 da 1, y elevada a 1 da la propia base. Además, aloga(u) = u.

Ejemplo: log5(1) = 0 y log3(34) = 4.
2

Propiedades Operativas de los Logaritmos

Herramientas para agrupar términos en un único logaritmo

Logaritmo de un producto Suma → Producto
loga(u · v) = loga(u) + loga(v)

La suma de dos logaritmos de la misma base equivale al logaritmo del producto de sus argumentos.

Ejemplo: log(x) + log(x - 3) = log(x(x - 3))
Logaritmo de un cociente Resta → Cociente
logauv = loga(u) - loga(v)

La diferencia de dos logaritmos de la misma base se transforma en el logaritmo del cociente.

Ejemplo: log2(x + 1) - log2(x) = log2((x + 1)/x)
Logaritmo de una potencia Coeficiente → Exponente
loga(un) = n · loga(u)

Un número que multiplica delante de un logaritmo pasa como exponente del argumento (también válido para raíces: √u = u1/2).

Ejemplo: 2·log(x) = log(x2)
Cambio de base Muy usado en examen
logb(u) = loga(u)loga(b)

Permite unificar logaritmos con bases distintas (como base 3 y base 9, o base 2 y base 8). Caso práctico: logak(u) = loga(u)k.

Ejemplo: log9(x) = log3(x)log3(9) = log3(x)2
Igualdad de logaritmos (Inyectividad) Despeje final
loga(u) = loga(v)  ⇒  u = v

Cuando logramos tener un único logaritmo en cada miembro con la misma base, igualamos sus argumentos.

Ejemplo: log(x2) = log(256) ⇒ x2 = 256
3

Estrategias para Ecuaciones Exponenciales

Los 4 métodos clave de 1.º de Bachillerato según la estructura de la ecuación

1. Igualación de bases Directo
af(x) = ag(x)  ⇒  f(x) = g(x)

Expresa ambos miembros como potencias de la misma base e iguala los exponentes.

Ejemplo: 32x-5 = 27 ⇒ 32x-5 = 33 ⇒ 2x - 5 = 3
2. Sacar factor común ax Sumas/Restas
ax+n = ax · an  |  ax-n = axan

Cuando aparecen sumas o restas de potencias de la misma base con exponentes lineales (x+1, x-1), descompón y extrae factor común ax.

Ejemplo: 2x+1 + 2x = 12 ⇒ 2x(2 + 1) = 12 ⇒ 2x = 4
3. Cambio de variable t = ax Cuadráticas
t = ax (con t > 0)  ⇒  a2x = (ax)2 = t2

Si aparecen a2x (o (a2)x) junto con ax, sustituye t = ax para resolver una ecuación de 2.º grado. Descarta siempre valores t ≤ 0.

Ejemplo: 9x - 4·3x + 3 = 0 ⇒ t2 - 4t + 3 = 0
4. Aplicar logaritmos Bases distintas
ax = b  ⇒  x · log(a) = log(b)  ⇒  x = log(b)log(a)

Cuando el término independiente b no es potencia exacta de la base a, toma logaritmos decimales o neperianos en ambos miembros.

Ejemplo: 3x = 12 ⇒ x = log(12)log(3) ≈ 2,26
